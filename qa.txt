1. Objective
The objective of this document is to verify that Login and Registration work correctly, validate user input, show useful error messages, and protect user accounts. Positive and negative scenarios are
included.
2. Scope and Assumptions
• Login authenticates registered users using email and password.
• Registration creates a new account using required user details.
• All email addresses and passwords are dummy test data. Use a test environment only.
• Follow the application's specified password rules, field limits, verification steps, and terms requirements. Cases marked 'if available' or 'if enabled' apply only when that feature exists.
• All cases are marked Not Executed because they have not been run against an actual application.
